# Формирование плана погрузки контейнерного поезда

Процедурная реализация на Python: программа проверяет данные контейнеров, распределяет контейнеры по платформам поезда, считает заполнение поезда в ДФЭ и проверяет норму 92%, определяет платформы, на которых нужно переставить упоры, и выводит список контейнеров, не вошедших в поезд

## Запуск

Python 3.13, внешних библиотек нет. Из папки `src`:

```
python main.py data/train_2041.json 2041
```

Аргументы: файл с данными, номер поезда и необязательный файл, в который сохраняется план погрузки:

```
python main.py data/train_2041.json 2041 plan.json
```

## Модули

| Файл | Что делает |
|---|---|
| `main.py` | разбор аргументов, выбор поезда, его платформ и контейнеров, порядок операций |
| `checks.py` | `check_containers()` - проверка данных контейнеров |
| `planner.py` | `distribute_containers()` - распределение контейнеров по платформам |
| `teu.py` | `container_teu()`, `calc_train_teu()` - расчет ДФЭ и заполнения поезда |
| `stops.py` | `find_stop_changes()` - платформы, на которых нужно переставить упоры |
| `storage.py` | чтение данных из JSON и сохранение плана погрузки |
| `output.py` | вывод плана в консоль |
| `constants.py` | нормативы: масса тяжелого контейнера, длины платформ, норма заполнения |

## Входные данные

JSON-файл со списками записей по логической модели данных: `organizers`, `requests`, `trains`,
`container_types`, `containers`, `platform_models`, `platforms`, `train_platforms`. Пример - `data/train_2041.json`:
поезд 2041 из восьми платформ (три 80-футовые, три 60-футовые, две 40-футовые) и 18 контейнеров
на три станции назначения.

Сохраненный план содержит запись `load_plan` и список `placements` (контейнер, платформа, позиция).
